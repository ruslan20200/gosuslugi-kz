# Госуслуги Казахстан (Клон)

Этот проект представляет собой мобильный фронтенд-клон приложения "Госуслуги Казахстан", разработанный на React + Tailwind CSS.

## Особенности

*   **Mobile First**: Дизайн оптимизирован для мобильных устройств (iPhone/Samsung). На десктопе интерфейс ограничен шириной 430px.
*   **Pixel Perfect**: Интерфейс максимально приближен к оригинальному дизайну из скриншотов.
*   **Удостоверение личности**:
    *   Визуализация документа (лицевая и оборотная стороны).
    *   Генерация MRZ кода.
    *   Загрузка собственного фото или PDF.
*   **QR-код**: Генерация динамического QR-кода для предъявления документа.
*   **Редактирование данных**: Возможность изменить все данные (ФИО, ИИН, даты и т.д.) во вкладке "Реквизиты".
*   **Сохранение**: Все данные и загруженные файлы сохраняются в `localStorage` браузера и доступны после перезагрузки.

## Установка и запуск

1.  **Установите зависимости**:
    ```bash
    npm install
    # или
    pnpm install
    ```

2.  **Запустите проект**:
    ```bash
    npm run dev
    # или
    pnpm dev
    ```

3.  Откройте в браузере ссылку, которая появится в терминале (обычно `http://localhost:5173` или `http://localhost:3000`).

## Как это работает

### Хранение данных (localStorage)
Все данные пользователя хранятся в браузере в ключе `gosuslugi_user_data`. Это включает:
*   Текстовые поля (ФИО, ИИН, номер документа и т.д.)
*   Фотографию (в формате base64)
*   PDF файл (в формате base64)

Кнопка "Очистить данные" (иконка корзины) удаляет этот ключ и возвращает данные по умолчанию.

### Генерация QR-кода
При нажатии на кнопку "Предъявить документ" генерируется QR-код, содержащий JSON-объект с текущими данными пользователя и временной меткой. Также генерируется случайный 6-значный код, который обновляется при каждом открытии.

### Загрузка файлов
Вы можете загрузить свое фото (JPG/PNG) или PDF файл.
*   Если загружено фото, оно отображается на удостоверении.
*   Если загружен PDF, он сохраняется, но для демонстрации на удостоверении используется заглушка или последнее загруженное фото (в реальном приложении потребовался бы рендеринг PDF).
